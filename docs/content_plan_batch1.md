## 選定の5基準（各記事を採点）

| 基準 | 意味 | 重み |
|---|---|---|
| **CVR距離** | 購買までの近さ（層M＞層1＞層0＞層1.5＞層3） | 高 |

## 第0：先に置く"受けページ"（記事群の帰着点）

### ⓪ 最安比較表 `/esim/{lang}/compare`（層M・全市場）
- **役割**: これは記事ではなく**受けページの核＝最安の証拠＝AI引用の主砲**（v9 §5-2・§9-1）。下記の記事の多くがここへ手渡す。
- **中身**: yah.mobile / Airalo / Holafly / 各国キャリアのローミングを **日数×価格×取得日時**で。自社価格はFirestore直結、他社のみ手動。出身国フィルタ（パーソナライズ＝自社面限定）。
- **迷わせない**: 「高いかも」を消す。**正直に**（短期・少容量で競合が勝つ条件も出す）→ 透明性＝説得力＝AI引用（数値+日付）。
- **これを最初に**。記事の受け皿がないと集客が漏れる。

## 推奨執筆順（＋理由）

### 🥇 まず #1 「일본 이심 카카오톡 인증」（単体ROI最大）
- **最大市場（韓国946万）× 最低競合（KO言語×具体の空白）× 購入前"最後の不安"（ジヨン・v9 §4-2）**を同時に取る。
- AIは韓国語のこの具体では引用元が乏しく、**実機スクショ＋確認日で一次情報化**すれば勝てる。
- **番号維持ツール→/buy**に直結＝離脱理由③を消してそのまま購買。
- 実訪問不要。**「最も効く1本」はこれ。**

### 🥈 次に ⓪比較表 → #2 → #3
- ⓪比較表を立て、#2（KO王道・最安）でそこへ流し、#3（SKTローミング）で高意図を刈る。**韓国で"迷わせない"の完成形（不安消し#1→比較#2→ローミング#3）を作る。**

### 🥉 #5（台湾ローミング）→ #4（タイ試掘）→ #6,7,8
- #5で台湾の高意図。#4は**タイの空白の試掘（ボリューム検証と一体・M2で判断）**。#6〜8で機種設定・VJW権威を足す。

## 記事の共通テンプレート（v9 §9-3/§9-4準拠）

```
[タイトル] 主クエリ1本を含む（言語ネイティブ）
[冒頭3行] 定義文＋数値で直接回答（例:「結論: eSIMでもKakaoTalkの認証は残る。番号は日本番号が付与されるが、
          既存アカウントの認証は◯◯の手順で維持できる。所要3分・2026年◯月確認」）
[本文見出し] 従クエリ5〜10を見出しに散らす
[実機スクショ] 確認日つき（一次情報化＝AI防衛の核）
[直接回答ブロック＋FAQ3問] （GEO：定義文+数値+日付で引用率↑）
[通信ブリッジ] → 該当の道具（番号維持/GB診断/自国キャリア比較/機種チェッカー）
[動的価格ウィジェット] 実勢価格・Airalo差（SSR・現地通貨・取得日時）＋ /buy?ref=
[Schema・ref/UTM・更新日・層/言語・配信先フィールド]
```
