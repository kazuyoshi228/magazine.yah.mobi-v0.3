## 6. 判断の規律（毎回思い出す）

1. **6ヶ月ラグ**。最初の低い数字＝失敗ではない。上向きの"傾き"を見る。
2. **記事別×言語別**で「刺さる組み合わせ」を見つける → **次に書く記事の材料**（＝検証の積み重ね）。
3. **知識系は流入でなくAI引用で測る**。換金系(1〜7)は流入＋予約CTA。
4. **KRボットを必ず除外**して実数を見る。
5. 台湾(zh)の動きを特に注視（需要最大市場）。
