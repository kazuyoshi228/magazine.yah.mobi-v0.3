# 台湾 eSIM — Google広告 検証テスト（実行パッケージ）

**目的**: SEO成熟(6ヶ月)を待つ間に、①実CVR ②勝つ角度 ③実CPC を2週間で実測する。獲得チャネル化できるかの判定材料を取る。

## ユニットエコノミクス（前提）
- 平均購買単価: **¥4,000**
- 粗利: **¥2,670**（粗利率67%）
- 損益分岐CPA = **¥2,670**（これ未満で獲得できれば黒字）
- **目標CPA = ¥1,800**（利益¥870/件を残す）
- 損益分岐CPC: CVR2%→¥53 / 3%→¥80 / 5%→¥133（台湾実CPC ¥30〜100）
- **判定の核心 = 実CVRが3%を超えるか**

## 判定計画（2週間後）
| 実CVR | 判定 | 次アクション |
|---|---|---|
| **≥3%** | 黒字獲得OK | 予算拡大＋勝ち角度で57記事SEO＝二本柱 |
| **2%前後** | 安い語のみ黒字 | 角度を絞って継続（native/compareの安い語） |
| **<2%** | 獲得は不可 | 広告停止・**学習成果(勝ち角度)だけ回収**→SEOへ |

**角度の勝敗も必ず見る**: price / native / compare のどれがCVを生んだか＝**57記事の"当たり角度"がここで確定**する（これが本テスト最大の収穫）。
